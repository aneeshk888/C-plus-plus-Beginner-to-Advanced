# Week-1


## Day 1 – Introduction to C++
Kick things off by understanding what C++ is, why it's still so widely used, and where it fits in the world of programming. We'll also help you set up your system so you're all set to run your first C++ program.
</br>
[DAY-1](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY1.md)

## Day 2 - Data Types and Variables
Learn how different types of data are stored in C++, how to declare and use variables, and how constants help lock in fixed values. Also look at the handy auto keyword to make your code cleaner and easier to write.
</br>
[DAY-2](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY2.md)

## Day 3 – Input/Output Operations
Get comfortable with getting input from users and displaying output using cin and cout. Also explore escape sequences for formatting text and take a quick look at bitwise operators for more advanced control.
</br>
[DAY-3](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY3.md)

## Day 4 – Operators in C++
Learn all about performing calculations. Use arithmetic and other operators, and understand how C++ decides the order in which operations run using precedence and associativity.
</br>
[DAY-4](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY4.md)

## Day 5 – Decision Making in C++
Learn how to make decisions in your programs using if, else, and switch statements. Also get to know how logical expressions and short-circuit evaluation can make your conditions smarter.
</br>
[DAY-5](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY5.md)

## Day 6 – Loops in C++
Explore how to repeat tasks using for, while, and do-while loops. Also cover break, continue, and even goto to get full control over how your loops behave.
</br>
[DAY-6](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY6.md)

## Day 7 – Weekly Project: Temperature Converter
Bring everything together by building a temperature converter that switches between Celsius and Fahrenheit. This fun mini project uses input, output, conditionals, and loops—everything you’ve learned this week!
</br>
[DAY-7](https://github.com/aneeshk888/C-plus-plus-Beginner-to-Advanced/blob/main/DAY7.md)
